# Advanced worked examples

These guides assume basic Python, familiarity with database queries, and ordinary
terminal use. Each starts with a small supported example
and explains the GraphForge concepts it needs. They are optional additions to
[basic graph use](../../guide/quickstart.md), not a required capability checklist.

For agent-assisted research without writing code, start
with [Your first research project](../../guide/first-research-project.md).
That Basic path connects observations, passages, interpretation, and a bounded
conclusion with guided or agent-assisted execution.

| Advanced guide                                                  | What you build                                                        |
| --------------------------------------------------------------- | --------------------------------------------------------------------- |
| [Knowledge graph construction](knowledge-graph-construction.md) | Source-linked mentions, explicit identity rules, candidate lookup     |
| [Network analysis](network-analysis.md)                         | Counts, paths, and native graph algorithms with scoped interpretation |
| [LLM-powered workflows](llm-workflows.md)                       | Proposed extraction, source inspection, and separate human review     |
| [Decision workflows](decision-workflows.md)                     | Validate external answers and apply an explicit caller policy         |
| [Agent grounding](agent-grounding.md)                           | A tool/capability graph for an application                            |
| [Agent tool recall](agent-tool-recall.md)                       | Candidate tools and declared input requirements                       |

Use the matching [installation](../../guide/installation.md) for these v0.6.0
docs. Examples state whether they are memory-only; follow
[save and reopen](../../guide/tutorial.md) before relying on persistence and
[portable projects](../../guide/portable-projects.md) for transfer.

[Research notes](../research/README.md) discuss interpretation and evaluation.
[Architecture](../architecture/overview.md) and
[engineering contracts](../../engineering/README.md) are separate expert
references, not prerequisites for these examples.
